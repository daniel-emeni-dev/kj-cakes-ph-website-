# KJ Cakes PH — Business Website

A luxury cake business website built for KJ Cakes PH, Port Harcourt, Nigeria.

## About the Project
KJ Cakes PH is a high-end cake brand specialising in bespoke, wedding, and celebration cakes. This website was built to establish their online presence, showcase their portfolio, and drive customer bookings via WhatsApp.

## Features
- Full brand website with hero section
- About the founder and brand story
- Gallery showcasing cake collections
- Services section
- WhatsApp booking integration
- Fully responsive and mobile-first

## Built With
- Next.js
- Tailwind CSS
- Deployed on Vercel
