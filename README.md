# KJ Cakes PH — Business Website

A responsive business website concept for KJ Cakes PH, a cake brand in Port Harcourt, Nigeria. The site is designed to showcase cake collections and services and give prospective customers a straightforward way to make enquiries through WhatsApp.

**Live site:** [v0-kj-cakes-ph-website.vercel.app](https://v0-kj-cakes-ph-website.vercel.app)

## Project goals

- Establish a clear online presence for the cake business.
- Showcase cake collections through a visual gallery.
- Explain the brand and its services.
- Make it easy for visitors to enquire or discuss an order through WhatsApp.
- Provide a mobile-friendly experience.

## Features

- Homepage with hero section.
- About section for the founder and brand story.
- Cake gallery and collection showcase.
- Services information.
- WhatsApp booking/contact entry point.
- Responsive layouts for mobile and desktop.

## Built with

- **Next.js** — web application framework
- **Tailwind CSS** — styling
- **Vercel** — deployment

## Run locally

You'll need Node.js and npm.

```bash
git clone https://github.com/daniel-emeni-dev/kj-cakes-ph-website-.git
cd kj-cakes-ph-website-
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Check the repository's source code and environment example for any project-specific setup needed locally.
